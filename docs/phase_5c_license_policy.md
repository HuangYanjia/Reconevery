# Phase 5C license policy

Every candidate records code, checkpoint, dependency, asset, training-data, and
commercial-review fields. Selection separately reports the best research candidate
and best production-eligible candidate.

- Measured analytic geometry follows the source observation policy.
- PartNet-Mobility is research-only.
- ArtVIP is blocked from production until exact asset approval.
- The current Particulate plus PartField stack is research-only.

No authentication token, dataset, or checkpoint is stored in Git or request
provenance.
